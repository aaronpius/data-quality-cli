# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-09-21

### Added
- CSV, Excel, JSON and optional Parquet loading
- Dataset and column profiling
- Duplicate-row detection
- Null-percentage checks
- Uniqueness checks
- Allowed-value checks
- Numeric minimum and maximum checks
- IQR-based numeric outlier counts
- YAML rule configuration
- Markdown and JSON report output
- CI-compatible non-zero exit code on failed checks
- Automated tests across Python 3.10, 3.11, 3.12 and 3.13
- Ruff linting in GitHub Actions
- Contributor guide, security policy and code of conduct
- Issue templates, pull request template and Dependabot configuration
